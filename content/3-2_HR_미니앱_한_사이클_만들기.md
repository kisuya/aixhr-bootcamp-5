# HR 미니앱 한 사이클 만들기

## 개요

3-1에서 연 Claude Code로 이번에는 근태 CSV를 고르면 부서별 근무시간과 주 52시간을 넘긴 직원을 보여 주는 대시보드를 만듭니다. 만든 파일은 인터넷 없이 돌아서, 사내망과 폐쇄망 안에서도 쓸 수 있습니다(5절).

**이 장의 실습**

| 실습 | 수업에서 |
|---|---|
| 실습 1. 화면을 말로 묘사해 뼈대 만들기 | 함께 완성 |
| 실습 2. CSV를 읽어 계산하게 하기 | 함께 완성 |
| 실습 3. 주 52시간을 넘긴 직원과 한 사람의 주간 합계 대조하기 | 함께 완성 |
| 실습 4. 사내 반입 전에 점검하기 | 함께 완성. 폐쇄망이 아니어도 사내에서 쓸 도구라면 같은 점검을 합니다 |

## 1. 만들 화면과 데이터가 가는 길

만들 것은 HTML 파일 하나입니다. 브라우저로 열고 내 PC의 근태 CSV를 고르면, 브라우저가 그 자리에서 파일을 읽어 주별 합계를 냅니다. 결과는 숫자 카드, 막대그래프, 표로 그려집니다.

**근태 파일의 내용은 어떤 서버로도 보내지 않습니다.** 다만 페이지가 외부 스크립트나 글꼴을 불러오면 그 서버와는 통신하므로, 요청에 외부 주소를 쓰지 말라는 조건을 직접 적고 실습 3에서 정말 그런지 확인합니다.

주 52시간은 근로기준법 제50조(1주 40시간)와 제53조(당사자가 합의하면 1주 12시간까지 연장)에서 나오고, 상시 5명 이상 사업장에 적용됩니다. 이 대시보드는 점검 도구입니다. 넘긴 사람이 나오면 탄력적 근로시간제나 특별연장근로 같은 예외가 적용되는지, 기록이 실제 근무와 같은지는 사람이 확인합니다.

> ⚠️ **주의** 실습 파일은 모두 교육용 가상 데이터입니다. '한결커머스'와 직원, 지원자, 응답은 강의를 위해 만든 것이며 실제 회사나 사람과 관계가 없습니다. 내 회사 데이터로 옮길 때는 [데이터 보안 기준](/guide/9-2/#2-실데이터를-쓰기-전에-확인할-것)부터 확인하세요.

## 2. 뼈대 만들기

### 실습 1. 화면을 말로 묘사해 뼈대 만들기

1. 문서 폴더처럼 찾기 쉬운 곳에 `attendance-dashboard` 폴더를 새로 만듭니다. 이 폴더는 3-3에서 GitHub에 올릴 폴더라 **근태 CSV는 넣지 않습니다.** CSV는 3-1에서 압축을 푼 `hangyeol_practice_data` 폴더에 그대로 둡니다.
2. Claude Code가 켜져 있으면 터미널 창을 닫고 새로 엽니다. 3-1 실습 1처럼 `cd`와 빈칸을 치고 새 폴더를 끌어다 놓아 그 폴더로 들어간 뒤, `claude`를 칩니다. 데스크톱 앱의 Code로 하는 분은 폴더를 고르는 곳에서 `attendance-dashboard` 폴더를 고릅니다. 처음 여는 폴더라 믿고 작업해도 되는지 묻는 화면이 나오면 허용합니다. 입력 칸 아래가 "auto mode on"이면 Shift + Tab으로 "manual mode on"으로 바꿉니다. 데스크톱 앱의 Code에서는 모드 선택에서 Manual을 고릅니다.
3. 아래 요청을 Claude Code 입력 칸에 붙여 넣습니다. 뼈대는 데이터 없이 화면 배치만 만드는 것입니다. 화면을 위에서 아래로 묘사해 요청하고, 나온 화면을 보며 하나씩 고칩니다.

```text
근태 CSV를 고르면 근무시간을 점검해 주는 대시보드를 만들려고 해.
오늘은 뼈대만 만들어 줘. 숫자와 표는 가짜 값으로 채워 둬도 돼.

화면은 위에서 아래로 이렇게 놓아 줘.
1. 제목 "근태 점검 대시보드"와 CSV 파일을 고르는 버튼.
   버튼 옆에 "파일은 이 브라우저 안에서만 읽고 어디에도 보내지 않습니다" 한 줄.
2. 숫자 카드 세 개: 읽은 행 수, 직원 수, 주 52시간을 넘긴 직원 수.
3. 주를 고르는 칸. 주는 월요일에 시작한다.
4. 고른 주의 부서별 1인 평균 근무시간 가로 막대그래프.
5. 주 52시간을 넘긴 직원 표: 사번, 이름, 부서, 근무유형, 주 시작일, 주간 합계. 합계가 큰 순서로.

조건:
- index.html 파일 하나로 만들어 줘. 외부 라이브러리나 외부 주소를 쓰지 말고, 인터넷이 끊겨도 열리게.
- 노무 담당자가 매달 한 번 열어 보는 화면이야. 색은 차분하게, 52시간을 넘긴 숫자만 빨간색으로.
- 다 만들면 브라우저로 열어 줘.
```

Claude Code가 만드는 동안 허락을 묻는 화면이 뜨면 무엇을 하려는지 읽고 허용합니다. 몇 분 걸리니, 그사이 GitHub(github.com)와 Vercel(vercel.com) 개인 계정이 없는 분은 가입해 둡니다. 3-3 실습 2(수업 뒤)에서 씁니다.

브라우저가 저절로 열리지 않으면 `attendance-dashboard` 폴더의 `index.html`을 더블클릭합니다. 고칠 곳은 보이는 대로 하나씩 말하고, 고칠 때마다 브라우저를 새로고침해 확인합니다. 예를 들면 이렇게 말합니다.

```text
숫자 카드가 너무 작아. 주 52시간을 넘긴 직원 수 카드를 가장 크게 해 줘.
```

## 3. 기능 넣기

### 실습 2. CSV를 읽어 계산하게 하기

**사용할 파일**: [attendance_2026-09.csv](/practice-files/attendance_2026-09.csv)

9월 근태 기록 6,146행입니다. 열은 사번, 이름, 부서, 근무일, 근무유형, 출근, 퇴근, 휴가입니다. 이 파일에는 함정이 하나 있습니다.

이 데이터가 진짜라면 이름과 사번이 붙은 인사 데이터라 3단계(개인정보)입니다. 지금 만드는 화면은 파일을 밖으로 보내지 않지만, 화면에 보이는 표는 여전히 개인 기록입니다.

계산 규칙은 내가 정해서 줍니다. 아래 규칙은 한결커머스 기준이고, 내 회사 규칙이 다르면 그 줄만 바꿉니다. 실습 1과 같은 Claude Code 대화에 붙여 넣습니다.

```text
이제 가짜 값을 지우고, 고른 CSV 파일을 읽어 진짜로 계산하게 바꿔 줘.

파일 모양:
- 첫 줄은 열 이름: 사번,이름,부서,근무일,근무유형,출근,퇴근,휴가
- 한 줄 예: HG1001,김승현,개발,2026-07-01,주간,09:00,18:38,
- 근무유형은 주간, 오전조, 오후조, 야간조. 휴가 칸은 비어 있거나 연차, 반차.

계산 규칙:
- 하루 근무시간 = 퇴근 - 출근 - 휴게. 휴게는 1시간이고, 반차인 날은 30분이다.
- 연차인 날은 출근과 퇴근이 비어 있고 0시간이다.
- 퇴근 시각이 출근 시각보다 이르면 자정을 넘긴 것이다. 다음 날 퇴근으로 계산하고, 근무일은 출근한 날로 본다.
- 직원별로 주(월요일 시작)마다 합계를 내고, 52시간을 넘으면 표에 올린다.
- 부서별 1인 평균은 고른 주에 기록이 있는 그 부서 직원들의 주간 합계 평균이다.
- 파일의 첫 날보다 앞이나 마지막 날보다 뒤에 걸친 주는 날짜가 빠진 주다. 주를 고르는 칸에서 그 주 이름 옆에 '일부 날짜만'이라고 표시해 줘.

완료 기준:
- 파일 내용은 브라우저 안에서만 처리하고 어떤 서버로도 보내지 마.
- 읽지 못한 행은 건너뛰고, 몇 행인지 화면에 [확인 필요]로 보여 줘.
- 다 고치면 무엇을 바꿨는지 세 줄로 알려 줘.
```

다 되면 브라우저를 새로고침하고, 버튼으로 `hangyeol_practice_data` 폴더의 `attendance_2026-09.csv`를 고릅니다.

> 💡 **생각할 시간** 결과를 보기 전에, 무엇을 확인하면 맞는지 알 수 있을지 하나만 정해 두세요.

**막히면 보이는 증상을 그대로 말합니다**

9월 파일을 골랐는데 주를 고르는 칸이 비어 있거나, 주 52시간을 넘긴 직원이 0명으로 나올 수 있습니다. [확인 필요]에 거의 모든 행이 걸리기도 합니다. 이 실습 데이터의 정답은 7명이라, 0명이 나오면 계산보다 날짜를 읽는 단계와 주를 고르는 기준부터 확인합니다. 7명은 모두 9월 14일 주에 있으니, 카드가 고른 주만 센다면 9월 14일 주를 골라 봅니다.

보이는 것과 파일 앞부분을 그대로 보여 줍니다. CSV는 엑셀 말고 메모장(맥은 텍스트 편집기)으로 엽니다. 파일을 오른쪽 클릭해 연결 프로그램에서 고르면 됩니다. 엑셀은 날짜 모양을 바꿔 보여 줘서 원래 모양을 알 수 없습니다.

아래 요청의 대괄호 칸은 메모장에서 내 상황으로 바꿔 쓴 뒤 통째로 붙여 넣습니다.

```text
9월 근태 파일을 골랐더니 [보이는 증상을 그대로. 예: 주 52시간을 넘긴 직원이 0명이고 주를 고르는 칸이 비어 있어].
파일 앞부분 세 줄은 이래.
[메모장으로 열어 첫 세 줄을 복사해 붙여 넣기]
원인을 찾아서 고쳐 줘. 앞으로 매달 다른 파일을 올릴 거니까 이런 차이에도 견디게 해 줘.
```

보통 이런 답이 옵니다.

> 9월 파일은 근무일이 2026.09.01처럼 점으로 구분되어 있어서, 하이픈 형식만 읽던 코드가 날짜를 읽지 못했습니다. 점, 하이픈, 빗금을 모두 읽도록 바꿨습니다.

**매달 쓰는 도구는 이런 차이에도 결과가 같아야 합니다.** 실데이터로 할 때는 앞부분 세 줄의 이름과 사번을 바꿔서 붙여 넣습니다.

Claude Code가 처음부터 여러 날짜 모양을 읽게 만들었다면 이 장면 없이 지나갑니다. 그래도 실습 3의 검수는 똑같이 합니다.

<details>
<summary>정답 예시 보기</summary>

파일을 올리면 아래처럼 나와야 합니다.

| 항목 | 값 |
|---|---|
| 읽은 행 수 | 6,146행, [확인 필요] 0행 |
| 직원 수 | 314명(파일 전체의 사번 수. 카드가 고른 주만 센다면 9월 14일 주는 309명) |
| 주 목록 | 8월 31일 주부터 9월 28일 주까지 다섯 주 |
| 주 52시간을 넘긴 직원 | 7명(모두 9월 14일 주) |

직원 수가 9월 말 재직자보다 많은 314명인 이유는 이 파일이 9월 한 달의 기록이기 때문입니다. 9월 말 재직자 308명에 9월 퇴사자 5명, 그리고 7월에 퇴사했는데 9월 기록이 남은 1명(HG4576)이 더해졌습니다. 2회차 정제 실습에서 찾은 퇴사 후 기록 중 하나입니다. 이 대시보드는 직원 명부와 대조하지 않으므로 이런 기록도 그대로 셉니다.

이 파일의 함정은 날짜 형식입니다. 7월과 8월 파일은 `2026-07-01`처럼 하이픈을 씁니다. 하이픈만 읽는 코드는 9월 파일의 모든 행을 놓치거나 주를 엉뚱하게 묶습니다.

</details>

## 4. 실행하고 숫자 검수하기

### 실습 3. 주 52시간을 넘긴 직원과 한 사람의 주간 합계 대조하기

**사용할 파일**: [attendance_2026-09.csv](/practice-files/attendance_2026-09.csv)

결과는 메모장이나 문서에 [1-3](/guide/1-3/#검수-3칸)의 검수 3칸(맞은 것, 틀린 것, 빠진 것)으로 적어 둡니다.

1. **행 수**: 읽은 행 수 카드가 파일의 데이터 행 수와 같은지 봅니다. 엑셀로 열었을 때 마지막 행 번호에서 머리글 한 줄을 뺀 값입니다.
2. **주 고르기**: 주를 9월 14일(월)에 시작하는 주로 바꿉니다. 처음에 다른 주가 골라져 있을 수 있습니다.
3. **표의 사람 수와 근무유형**: 주 52시간을 넘긴 직원이 몇 명인지 세고, 근무유형 칸에 야간조나 오후조가 있는지 봅니다. 자정을 넘긴 근무를 잘못 계산하면 이 사람들이 빠집니다.
4. **손 대조**: 표 맨 위 사람의 사번을 적고, 엑셀에서 사번 열을 그 값으로 필터해 그 주 기록 5줄을 찾습니다. 하루씩 퇴근 시각에서 출근 시각과 휴게 1시간을 빼서 메모장이나 문서에 적습니다. 날짜, 출근, 퇴근, 근무시간을 한 줄에 하루씩 적고, 맨 아래에 합계를 냅니다. 다 보면 엑셀은 저장하지 않고 닫습니다. 저장하면 날짜 모양과 인코딩이 바뀌어 다음 검수 때 같은 결과가 나오지 않습니다.
5. **인터넷 없이 도는지**: Wi-Fi를 끄고 `index.html`을 새로 열어 파일을 다시 골라 봅니다. 결과가 그대로 나오면 이 화면은 바깥과 연결하지 않고도 계산한다는 뜻입니다. 확인이 끝나면 Wi-Fi를 다시 켭니다.
6. **밖으로 보내지 않는지**: Wi-Fi를 다시 켠 뒤 `index.html`을 Chrome으로 엽니다. 기본 브라우저가 Chrome이 아니면 파일을 오른쪽 클릭해 연결 프로그램에서 Chrome을 고릅니다.
   - 개발자 도구(페이지가 주고받는 요청을 보여 주는 Chrome의 개발자용 창)를 엽니다. 맥은 ⌥ + ⌘ + I, 윈도우는 Ctrl + Shift + I입니다. 위쪽 탭에서 "Network"(한국어 화면에서는 "네트워크")를 누릅니다.
   - 왼쪽 위 기록 버튼(빨간 점)이 켜져 있고, 필터 칸이 비어 있고, "All"이 골라져 있는지 봅니다. 그 창을 열어 둔 채 페이지를 새로고침하고, 9월 파일을 다시 고릅니다.
   - 목록의 이름 칸에 `index.html` 한 줄만 있으면 바깥으로 나간 요청이 없는 것입니다. 다른 줄이 보이면 그 줄을 눌러 Headers의 Request URL이 `http`나 `https`로 시작하는지 봅니다.

## 5. 사내망과 폐쇄망에서 쓰기

이 대시보드는 HTML 파일 하나이고, 실습 3에서 확인했듯 인터넷 없이 돌고 바깥으로 보내는 요청이 없습니다. 그래서 인터넷이 막힌 사내 PC에서도 쓸 수 있는 모양입니다.

폐쇄망(망분리 환경) 안에서는 Claude를 쓸 수 없으니, 만드는 곳과 쓰는 곳을 나눕니다.

| 단계 | 어디서 | 하는 일 |
|---|---|---|
| 만들기 | 인터넷이 되는 PC | 실데이터와 열 이름이 같은 가짜 데이터로 만들고 고친다. 실데이터는 이 PC로 가져오지 않는다 |
| 점검 | 같은 PC | 인터넷을 끄고 돌려 보고, 바깥으로 나가는 요청이 없는지 본다(실습 3의 5, 6번). 아래 실습 4를 한다 |
| 옮기기 | 회사가 정한 절차 | 회사의 자료 반입 절차로 파일을 옮긴다. 보안 검토가 있으면 설명서를 함께 낸다 |
| 쓰기 | 사내 PC | 실데이터로 연다. 실데이터와 결과 화면은 밖으로 가지고 나오지 않는다 |

### 실습 4. 사내 반입 전에 점검하기

**사용할 파일**: [attendance_2026-08.csv](/practice-files/attendance_2026-08.csv)

사내 시스템에서 내려받은 CSV는 한글 인코딩이 다를 때가 많습니다. 8월 근태 파일은 [2-3](/guide/2-3/#실습-2-근태-csv-세-개를-정제해-하나로-합치기)에서 Cowork로 정제할 때 본 것처럼 인코딩이 CP949라, 9월 파일로만 시험한 대시보드에서는 이름과 부서가 깨질 수 있습니다.

실습 3과 같은 Claude Code 대화에 붙여 넣습니다. 대괄호 칸은 내 회사 PC 기준으로 채우고, 모르면 그대로 둡니다.

```text

1. 외부 주소(스크립트, 글꼴, 이미지, 요청)가 하나라도 있으면 없애고 파일 하나로 돌게 해 줘.
2. 사내 PC의 브라우저는 [브라우저 이름과 버전. 모르면 확인 필요]야. 이 브라우저에서 안 될 만한 기능이 있으면 알려 줘.
3. 사내 시스템에서 내려받은 CSV는 한글 인코딩이 CP949일 수 있어. UTF-8과 CP949를 모두 읽게 해 줘.
4. 읽지 못한 행이 있으면 몇 번째 행인지와 이유만 화면에 보여 줘. 그 행의 내용은 보여 주지 마.
5. 보안 검토에 낼 설명서를 README_반입.md로 만들어 줘. 무엇을 하는 파일인지, 읽는 파일과 열, 저장하는 것, 네트워크를 쓰지 않는다는 점과 그것을 확인하는 방법을 적어 줘.
다 하면 바꾼 것을 세 줄로 알려 줘.
```

다 되면 브라우저를 새로고침하고 `hangyeol_practice_data` 폴더의 `attendance_2026-08.csv`를 고릅니다. 이름과 부서가 한글로 보이는지, 읽은 행 수가 맞는지 봅니다. 코드를 고쳤으니 실습 3의 5, 6번(인터넷을 끄고 열기, Network 탭)도 다시 합니다.

## 6. 같은 순서로 만드는 다른 예: 면접 일정 신청 페이지

채용 담당이라면 근태 대신 면접 일정 신청 페이지를 같은 순서로 만들 수 있습니다. 해 볼 때는 `attendance-dashboard`가 아닌 새 폴더에서 Claude Code를 엽니다. 같은 폴더에서 하면 근태 대시보드의 `index.html`을 덮어씁니다.

| 순서 | 근태 점검 대시보드 | 면접 일정 신청 페이지 |
|---|---|---|
| 뼈대 | 숫자 카드, 막대그래프, 표를 위에서 아래로 묘사 | 포지션 안내, 고를 수 있는 시간 목록, 이름과 연락처 칸, 신청 버튼을 위에서 아래로 묘사 |
| 기능 | CSV를 읽고 계산 규칙대로 합계 내기 | 신청을 받고, 이미 찬 시간은 고르지 못하게 하기 |
| 실행 | 7명과 한 사람의 주간 합계 대조 | 같은 시간에 두 번 신청해 두 번째가 막히는지 확인 |

```text
면접 일정 신청 페이지의 뼈대를 index.html 하나로 만들어 줘. 시간 목록은 가짜 값으로 채워 둬.

화면은 위에서 아래로:
1. 포지션 이름과 면접 안내 한 줄
2. 고를 수 있는 날짜와 시간 목록. 이미 찬 시간은 회색으로
3. 이름, 휴대폰 번호 칸
4. 신청 버튼 하나

지원자가 휴대폰으로 여는 화면이야. 글자는 크게, 버튼은 하나만.
아직 신청 내용을 어디에도 저장하지 마.
```

다른 점이 하나 있습니다. 근태 대시보드는 데이터가 브라우저 밖으로 나가지 않지만, 신청 페이지는 지원자의 이름과 연락처를 받아 어딘가에 저장해야 합니다. 저장할 서버가 필요하고, 받는 순간 개인정보를 모으는 화면이 됩니다. 기능을 넣기 전에 [3-3의 배포 전 보안 점검](/guide/3-3/#4-배포-전-보안-점검)부터 읽으세요.

Claude Code 없이 Artifact로 비슷한 화면을 만드는 길도 있습니다. Pro 이상에서는 Artifact 안에 입력을 저장해 둘 수 있습니다. 개인 저장 공간에 넣은 값은 넣은 사람만 보고, 공유 저장 공간에 넣은 값은 여는 사람 모두가 봅니다.

신청을 공유 저장 공간에 쌓으면 여는 사람 모두가 같은 신청 현황을 봅니다. 다만 새 Artifact는 받는 사람도 Claude 계정에 로그인해야 열려서([1-2](/guide/1-2/#실습-3-이번-주-업무-정리-문서-만들기)) 지원자용으로는 맞지 않습니다. 사내 교육 신청처럼 Claude 계정이 있는 직원끼리 쓰는 일에 맞습니다. 공유 저장 공간은 여는 사람 모두가 보므로 휴대폰 번호 같은 연락처는 받지 않습니다.

## 도전 과제

실습을 먼저 끝낸 분이 이어서 해 볼 심화 과제입니다. 수업 뒤에 해도 됩니다.

### 도전 1. 두 달 파일을 함께 골라 경계 주를 채우기

지금 대시보드는 파일 하나만 읽어서 8월 31일 주가 "일부 날짜만"으로 나옵니다. 8월 파일과 9월 파일을 함께 읽게 바꾸면 그 주를 한 주 전체로 계산할 수 있습니다. `attendance-dashboard` 폴더의 Claude Code 대화에 아래를 붙여 넣습니다.

```text
CSV 파일을 여러 개 함께 고를 수 있게 바꿔 줘. 고른 파일의 행을 합쳐서 주를 계산해 줘.
파일마다 날짜 모양과 글자 인코딩이 다를 수 있어. 읽지 못한 행이 있으면 파일별 건수를 [확인 필요]와 함께 화면에 보여 줘.
외부 주소는 쓰지 마.
```

파일 고르는 창에서 Ctrl(맥은 ⌘)을 누른 채 8월과 9월 파일을 함께 고릅니다. 읽은 행 수가 12,312행(6,166 + 6,146)이면 둘 다 읽은 것입니다. 8월 31일 주의 "일부 날짜만" 표시가 사라지는지 봅니다. 9월 28일 주에는 그대로 남습니다. 9월 14일 주의 결과(주 52시간을 넘긴 직원 7명, 표 맨 위 58.40시간)는 그대로여야 합니다. 직원 이름이 깨져 보이면 그 증상을 그대로 말합니다.

### 도전 2. 부서 필터와 CSV 내보내기 넣기

대시보드에 두 가지를 더해 봅니다. `attendance-dashboard` 폴더의 Claude Code 대화에 아래를 붙여 넣습니다.

```text
대시보드에 두 가지를 더해 줘.
1. 부서 필터: 맨 위에 부서를 고르는 칸을 두고 "전체"를 기본값으로 해 줘. 부서를 고르면 숫자 카드, 막대그래프, 표가 모두 그 부서 기준으로 바뀌게.
2. 내보내기: 주 52시간을 넘긴 직원 표를 CSV 파일로 내려받는 버튼. 지금 화면에 보이는 행만 담아 줘.

조건: 계산과 내보내기 모두 지금처럼 브라우저 안에서만 해 줘. 다 하면 바꾼 것을 세 줄로 알려 줘.
```

다 되면 브라우저를 새로고침하고 9월 파일을 다시 고릅니다. 주는 9월 14일 주로 두고 부서를 몇 개 바꿔 봅니다. 그다음 부서를 "전체"로 두고 내보내기 버튼을 눌러 CSV를 내려받아 엑셀로 엽니다. 내려받은 CSV에는 이름과 사번이 들어 있어 원본과 같은 3단계(개인정보)입니다. 이 앱을 사내로 옮길 생각이면 실습 4의 점검을 다시 하고, `README_반입.md`에 내보내기 버튼을 적어 달라고 합니다.

버튼을 눌러도 아무 일이 없으면 [3-3의 혼자 키우는 순서](/guide/3-3/#혼자-키우는-순서) 4번처럼 브라우저 콘솔의 오류를 그대로 붙여 넣습니다. 엑셀에서 한글이 깨지면 그 증상도 그대로 말합니다.
